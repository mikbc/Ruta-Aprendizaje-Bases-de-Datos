# 📚 Ruta de aprendizaje — Bases de Datos y Desarrollo

Repositorio dedicado a documentar mi aprendizaje y práctica durante la asignatura **Laboratorio II**, con foco en **bases de datos, SQL, PL/SQL, ORM y tecnologías de persistencia de datos**.

Este proyecto funciona como una combinación de **bitácora de aprendizaje y portfolio técnico**, donde registro conceptos, ejercicios, resoluciones y trabajos prácticos desarrollados a lo largo de la cursada.

El objetivo no es únicamente almacenar las soluciones, sino **documentar el proceso de aprendizaje, las herramientas utilizadas y la evolución de mis conocimientos**.

## 🚀 Tecnologías y herramientas

### Bases de datos y lenguajes

* 🗄️ **Oracle Database**
* 🔹 **SQL**
* 🔹 **PL/SQL**
* 📦 **Hibernate**
* 🔄 **ORM (Object-Relational Mapping)**
* 🟢 **Bases de datos NoSQL**
* 📄 **JSON**

### Entorno de desarrollo

* 💻 **Oracle SQL Developer** — utilizado como IDE para el desarrollo y trabajo local con Oracle Database.

## 🧠 Conceptos trabajados

A lo largo de la cursada se abordan diferentes conceptos relacionados con el desarrollo y la gestión de bases de datos:

* Consultas y operaciones con **SQL**.
* Programación procedural mediante **PL/SQL**.
* Bloques anónimos y estructuras de control.
* Variables y tipos de datos.
* Cursores.
* Manejo de excepciones.
* Procedimientos almacenados.
* Funciones.
* Paquetes.
* Integración entre aplicaciones y bases de datos mediante **ORM**.
* Persistencia de objetos con **Hibernate**.
* Conceptos y estructuras de bases de datos **NoSQL**.
* Intercambio y manejo de información mediante **JSON**.

## 🎯 Objetivos de aprendizaje

Este repositorio forma parte de mi proceso de formación como programadora y busca reforzar especialmente:

* Diseñar y ejecutar consultas utilizando **SQL**.
* Desarrollar soluciones utilizando **PL/SQL**.
* Comprender la programación y lógica del lado de la base de datos.
* Trabajar con procedimientos, funciones, paquetes y cursores.
* Gestionar errores mediante mecanismos de excepción.
* Comprender el concepto de **persistencia de datos**.
* Aplicar conceptos de **ORM** utilizando Hibernate.
* Explorar las diferencias entre bases de datos relacionales y **NoSQL**.
* Trabajar con estructuras de datos en formato **JSON**.
* Documentar soluciones y mantener un registro organizado del aprendizaje.

## 📈 Progreso y documentación

El contenido se incorpora progresivamente a medida que avanza la cursada.

Cada ejercicio y actividad representa una oportunidad para **aplicar conceptos teóricos, resolver problemas y documentar las decisiones tomadas durante el desarrollo**.

Este entorno permite trabajar con las bases de datos, ejecutar consultas SQL, desarrollar código PL/SQL y realizar pruebas durante la resolución de los ejercicios.
